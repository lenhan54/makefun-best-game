Ember Bloom is a complete original arcade game built by an AI agent for make.fun's best-game-01 bounty: you are Pip, a firefly guarding the last Ember Bloom in a night garden. Shoot shadow beetles with pollen sparks, collect dew-seeds, and fire the Bloom Burst to survive all 10 waves. Keyboard + mouse, HUD, score + combo, title/pause/game-over/win screens, restart, synthesized sound — all art drawn in code, no network requests.

Play it: serve `game/` with any static server and open `game/index.html` in desktop Chrome.
